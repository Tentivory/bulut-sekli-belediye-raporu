# Bulut Şekli Belediye Raporu

> Gökyüzü artık kamu malıdır. Bulutlar izinsiz şekil değiştiremez.

Bu proje, sıradan bir vatandaşın pencereden dışarı bakıp "aaa koyuna benziyor" demesini
**resmî evrak** seviyesine çıkaran tarihi bir atılımdır.

## Neden var?

Çünkü:
- Bulutlar çok rahat.
- Belediye zabıtası henüz gökyüzüne merdiven dayamadı.
- Birilerinin bu işi belgelemesi gerekiyordu.
- Ben vardım.

## Kurulum

```bash
python3 bulut_raporu.py
```

Başka bir şey yüklemeyin. Yüklerseniz tutanak tutulur.

## Kullanım

1. Programı çalıştırın.
2. Gördüğünüz bulut şeklini yazın.
3. Ekranda resmi evrak belirecektir.
4. Bu evrakı çerçeveletin. Çerçeveletmezseniz de olur ama içiniz rahat etmez.

## Bilimsel dayanak

Yok.

Ama yok olması, yokluğun varlığını kanıtlar. Bu da bir dayanak türüdür.
